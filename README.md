# Kaffe Grus - Webbplatsprojekt

Detta är ett webplats för en fiktiv kaffeteria. Webbplatsen är planerad, designad och utvecklad från grunden som ett examinationsprojekt.

## Projektets syfte och målgrupp

- **Avsändare:** Kaffe Grus (modern och mysigt kaffé)
- **Målgrupp:** kaffe älskare, fikasugna lokala invånare samt studenter/distansarbetare som söker en arbetsplats
- **kommunikativt syfte:** Att vissa meny, inbjuda känsla till den fysiska kaffeterian.

## Design och planering

Innan utvecklingen påbörjades har en tydlig visuell struktur och grafisk profil planerats. Allt designunderlag finns sparat i projektets repository under katalogen `/design`.

Underlaget har tagits fram i **Figam** och består av:

- **Wireframes (Trådskisser):** Skisser som visar webbplatsens planerade layout för både mindre skärmar (mobil-first) och större skärmar (dator).
- **Designskiss/Mockup:** En visuell skiss som visar projektets grafiska profil med tänkta färger, typografi, bilder och grafiska element anpassade för målgruppen.
- **Figma Projekt:** (https://www.figma.com/design/5zdae1WtT0QFWQPceXDazZ/Caf%C3%A9-Miun?node-id=0-1&p=f&t=lVlnqzx98dDYgIcJ-0)

## Tekniska struktur

Projektet är byggd med:

- **HTML5**: För semantisk och tillgänglighet.
- **CSS**: För visuell desin och responsiv layout.
- **JavaScript**: För interaktivetet på webbplatsen.
